# Mochi_Setup

Mochi_Setup is a Windows desktop application for Minecraft: Java Edition.

The application is designed to help users manage:

- Minecraft versions
- NeoForge
- Minecraft mods
- Iris
- Shader packs
- Personal Mochi settings

Users sign in with their own Microsoft account.

Mochi_Setup uses Microsoft authentication, Xbox Live/XSTS authentication and Minecraft Services to verify the user's Minecraft: Java Edition profile.

Mochi_Setup does not collect or store Microsoft account passwords.

Mochi_Setup uses its own Microsoft Entra application registration and Client ID.

Mochi_Setup is an independent project and is not affiliated with or endorsed by Microsoft, Mojang or Minecraft.
